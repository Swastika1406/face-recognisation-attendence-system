
# AI Voice Assistant

A modern GUI-based AI Voice Assistant built using Python and CustomTkinter.

## Features

- Voice Recognition
- Voice Response
- Google Search
- YouTube Search
- Play Music
- Dark Mode GUI
- Live Clock
- Modern Buttons
- Scrollable Chat Window

## Technologies Used

- Python
- CustomTkinter
- SpeechRecognition
- pyttsx3
- pywhatkit
- Wikipedia API

## Installation

pip install -r requirements.txt

## Run Project
python gui.py
