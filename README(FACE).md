
# Face Recognition Attendance System

A Python-based face recognition attendance system using OpenCV and LBPH algorithm.

## Features
- Face registration
- Face recognition
- Automatic attendance
- GUI interface
- Duplicate prevention

## Technologies Used
- Python
- OpenCV
- Tkinter
- NumPy

## How to Run

1. Register faces
python capture.py

2. Train model
python train.py

3. Start attendance system
python main_gui.py
